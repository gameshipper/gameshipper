# Security

Please don't report security problems in a public issue.

Report them privately instead, either:

- with GitHub's **Report a vulnerability** button on this repository's Security tab, or
- by email to **dev@gameshipper.com**.

Say what's affected (the Gameshipper version, and the command or the built game), how to reproduce it, and what an
attacker could do with it. You'll get an answer within a week. Once a fix is released, the report can be made public,
with credit to you if you'd like it.

Gameshipper handles things worth protecting: the games it packages, the Steam, itch.io and GitHub logins it hands to
SteamCMD, butler and GitHub's API, and Apple signing credentials. Problems in any of those are in scope, as are ways a
game built with Gameshipper could be made to run code or open pages it shouldn't.

Only the latest release gets security fixes.
